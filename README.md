# Maritime3DOrbis

Maritime3DOrbis is an interactive 3D maritime equipment visualization and inspection dashboard developed using Three.js and modern web technologies.

## Live Demo

https://maritime3-d-orbis-zeta.vercel.app

## Project Overview

The project provides an interactive digital platform for viewing and inspecting maritime equipment through a 3D model.

Users can:

- View a 3D centrifugal pump model
- Rotate and zoom the 3D model
- Select individual equipment components
- View engineering information
- Inspect component condition and status
- Reset the camera view
- Interact with the equipment through a digital dashboard

## Features

- Interactive 3D model visualization
- Component-based equipment inspection
- Engineering data display
- Camera rotation and zoom controls
- Component highlighting
- Industrial maritime dashboard interface
- Web-based deployment using Vercel
