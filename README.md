# Maritime3DOrbis

Maritime3DOrbis is an interactive 3D maritime equipment visualization and inspection dashboard developed using Three.js and modern web technologies.

The project allows users to view a 3D centrifugal pump model, select individual components, inspect engineering information, and interact with the model through camera controls.

## Live Demo

https://shivaramakrishna369.github.io/Maritime3DOrbis/

## Features

- Interactive 3D centrifugal pump visualization
- Component-wise asset selection
- Highlighting of selected components
- Automatic camera focus on selected components
- Zoom, rotation, and pan controls
- Engineering information panel
- Component status display
- Dark industrial maritime dashboard interface
- Responsive dashboard layout
- Web-based 3D model inspection

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- Vite
- GitHub Pages
- GLB 3D Model Format
